# README screenshots

Add PNG or WebP files here (recommended width: **1280px** or **1920px**). GitHub displays them in the root [README.md](../../README.md).

| File | What to capture |
|------|-----------------|
| `landing.png` | Marketing homepage (signed out) — hero + features |
| `dashboard.png` | Dashboard overview — stats and recent activity |
| `interview-questions.png` | Interview detail — generated questions list |
| `interview-session.png` | Live mock interview — voice recorder / answer UI |
| `resume-analysis.png` | Resume analysis page — scores and feedback |
| `roadmap.png` | Roadmaps page — generated improvement plan |
| `analytics.png` | *(optional)* Analytics dashboard |

## How to capture (Windows)

1. Open [https://interv-ai-zeta.vercel.app/](https://interv-ai-zeta.vercel.app/) and sign in.
2. Navigate to each screen above.
3. **Win + Shift + S** → select area → save into this folder with the exact filenames.
4. Commit and push:

```powershell
git add docs/images/*.png README.md
git commit -m "docs: add README screenshots"
git push
```

Use dark mode in the app if you want screenshots to match the live UI theme.
